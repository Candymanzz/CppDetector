## Method and contract

`src/inspect/seam_mask.cpp` samples the actual full-resolution source along the
two-point band. Gaussian prefiltering and Canny hysteresis (`mask_low=8`,
`mask_high=24`) generate a binary edge mask. These are **edge/gradient thresholds**,
not absolute image brightness limits. Edges transverse to the seam, unavailable
source neighborhoods and explicitly excluded rows are removed.

Dynamic programming finds a continuous, bounded path for each gradient polarity,
with a small change-of-direction penalty. Up to two supported neighboring edges
are checked; the second requires overlapping evidence and median spacing 1–16 px.
A robust quadratic fit supplies the smooth baseline, matching the cylindrical
curvature allowance. Actual observed deviations are compared with the existing
middle/end tolerances. The DP path is only a search hypothesis: a bridged blank
row stays unmeasured, `deviation: null`, and contributes to the missing-length
guard. It never becomes a fabricated normal observation.

`mask_coverage` defaults to 0.70 and `mask_max_gap` to 0.20 of eligible rows.
Insufficient support, excessive continuous gaps, short/invalid lines and endpoints
outside the image make `control_complete=false`, `verdict=NOT_INSPECTED` with
`seam_mask_not_found`, `seam_mask_gap`, `seam_mask_line_invalid` or
`seam_mask_outside_frame`. Native mode keeps its original missing-line policy;
sensitivity zero still bypasses seam measurement.

Settings round-trip through `camera.seam`; result `seam` adds `search_method`,
`control_complete`, `mask_reason`, `gap`, `mask_sides` and `mask_preview` to the
existing metrics/samples. `GET /api/seam_mask?cam=N&version=V` returns the last
matching PNG, or 409 for stale/missing data. The preview shows the real source
strip above the real binary mask, with only observed path points overlaid.
It is stored only with the current overlay, not in profiles or learned cases.

The right-hand seam menu offers **Маска + связный путь**, threshold/coverage/gap
controls and the clickable mask preview. Coupled sliders keep low ≤ high; invalid
API pairs fail atomically. Camera changes clear old previews. The fixed bucket
view and persistent compact verdict remain intact.
