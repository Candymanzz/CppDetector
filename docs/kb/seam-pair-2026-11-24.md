## Behavior and implementation

The active ridge mask now calls `inspectMaskedSeam` in `src/inspect/seam_pair.cpp`.
The original `measureMaskedSeam` remains the extraction primitive used by reference
preparation and single-edge step mode. Captured-reference mode remains separate.

- The primary camera reference automatically identifies two supported opposite
  gradient paths with the existing Canny thresholds and configured band. No capture
  button or additional image is required. Insufficient reference pair support gives
  NOT_INSPECTED / `seam_mask_reference_pair`; ridge never silently becomes one side.
- Normal cross-sections follow the configured axis, with existing whole-image X/Y
  compensation, or the adaptive path's rectified image. Each polarity has its own
  connected DP path, evidence states and deviations. Appearance ranks actual Canny
  candidates softly; differing print or brightness cannot by itself erase a candidate.
  Search reaches max(8, band) pixels from each reference guide; a fixed 20 px strip
  margin allows observations outside the normal band. Search is independent of limits.
- Observed reference offsets use the exact runtime grid and the identical solver,
  giving zero self-deviation. Short interpolation guides search only. Reference
  evidence that is absent stays state 4; missing current evidence is state 3. Both
  serialize null deviations. There is no current-image fit that redefines the baseline.
- The existing middle/end tolerances apply independently to both side deviations.
  Width is the distance between the two observed sides, compared to that same
  section of the reference. Width allowance is max(1 source px, reference width ×
  `mask_width_tolerance`). Default relative allowance is .50 (50%). Crossed paths
  are unavailable evidence, not an accepted reversed pair.
- `mask_defect_run` defaults to 6 source pixels (range 3–100). A reference-supported
  side missing for that many consecutive sections, or a width violation lasting
  that long, rejects with `seam_mask_side_missing` / `seam_mask_width`. It is separate
  from the global 70% coverage and 20% longest-gap guards; those still yield incomplete
  control when failed. Excluded and ignored end rows reset local runs.

The two new settings persist and validate atomically. The local model is prepared
per inspection from current reference pixels/settings; there is no stale pair cache
or new confirmation lifecycle. The existing reference-only mode is unchanged.
Sensitivity zero still bypasses seam inspection. Missing endpoints in enabled mask
mode now produce incomplete control instead of skipping the check silently.

JSON seam diagnostics add `paired_mask`, `reference_coverage`, `sides` (polarity,
coverage, longest_missing_px, samples), width/run limits and per-row current/reference
width. Aggregate coverage requires both sides, and includes unknown reference sections
as unmeasured. Per-side coverage is relative to that side's supported reference rows.
Source overlay and versioned mask PNG show both measured paths, cross-sections,
missing expected positions and limits. The graph distinguishes both sides and never
joins measurements across missing rows. The fixed bucket and independent right scroll
are retained. The method selector is directly visible; reference capture controls
appear only in the separate reference mode.
