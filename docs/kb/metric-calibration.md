# Допуски на смещение в миллиметрах

По просьбе пользователя калибровка временно убрана из интерфейса. Оба допуска в мм доступны сразу.
Используется предварительный масштаб каждой камеры; точные коэффициенты будут уточняться опытным путём.
Известные размеры ведра: диаметр дна 190 мм, верхний диаметр 193 мм, высота вдоль оси 213 мм.

## Временные коэффициенты

Грубая оценка по видимому размеру ведра на кадрах 1224×1024, мм на исходный пиксель:

| Камера | Горизонталь | Вертикаль |
|---|---:|---:|
| 0 | 0.25 | 0.33 |
| 1 | 0.28 | 0.32 |
| 2 | 0.31 | 0.31 |
| 3 | 0.25 | 0.32 |
| 4 | 0.27 | 0.34 |
| 5 | 0.27 | 0.34 |
| 6 | 0.25 | 0.33 |
| 7 | 0.22 | 0.23 |
| 8 | 0.22 | 0.32 |
| 9 | 0.28 | 0.33 |

Эти оценки не являются измеренной калибровкой. В интерфейсе есть краткая отметка, что мм пока приблизительные.
Сохранённые коэффициенты `estimated_mm_per_pixel` можно уточнить отдельно для каждой камеры.

## Настройки и масштаб

`horizontal_shift_tolerance_mm` и `vertical_shift_tolerance_mm` задают допуски на смещение по горизонтали и вертикали.
При первом запуске прежние пиксельные значения переводятся во временные мм, а сохранённые значения в мм сохраняются.

Коэффициенты привязаны к разрешению 1224×1024:
`mm_per_pixel_x = estimated_x * 1224 / current_width`, аналогично по вертикали с высотой 1024.
`tolerance_px = tolerance_mm / mm_per_pixel`. В пиксели рабочего разрешения значение округляется один раз,
после применения Downscale. Зум браузера в расчёте не участвует.

Общий сдвиг сравнивается с заданным допуском в мм. Для локальной дискретной маски остаётся округление
до ближайшего пикселя анализа. Уменьшение разрешения ограничивает пространственную точность.

## Диагностика и будущее уточнение

`metric_scale_source=estimated` отличает временные коэффициенты от измеренных.
Результаты включают `shift_mm`, `shift_raw_mm`, `shift_limit_mm`, `effective_shift_tolerance_mm`,
`analysis_pixel_mm` и `mm_per_pixel`. Backend сохраняет совместимость с уже записанной калибровкой,
но разметки отрезков, соответствующей карточки и блокировки настроек в интерфейсе больше нет.
