# Seam plot, width events and used settings — 2026-11-24

The owner saw a local anomaly on the seam overlay without a clear event on its
bottom graph and suspected their tuning. Two effects were confirmed separately.

## Diagnosis

At one live read camera 6 used middle/end limits 27.5/28.5 px, Canny thresholds
0/0 and a local defect length of 29 px. Its latest f95 result had maximum geometric
deviation 8.15 px and a width-change run of 19 px. Both are below those respective
rejection limits. Canny 0/0 accepts very weak candidate gradients, including noise.
The owner continued changing parameters during this task (the staged snapshot
already had run length 32 and different coverage/gap limits). These are dated
observations, not a recommendation or a permanent machine configuration. The small
attached crops do not prove that their original frame was that latest f95 result.

The separate SVG already plotted both sides, but the C++ bottom graph still used
only the aggregate deviation: it omitted width and independent missing-side lanes.
Also, after drawing both actual paths, the source overlay drew an extra aggregate
polyline. Its worst-side selection could alternate from one side to the other,
creating a decorative zigzag that was not either measured boundary.

## Change

- Paired mode draws only its two measured paths on the source, without that extra
  aggregate connecting line. Consecutive missing observations are not joined.
- The C++ bottom graph now shows both geometric traces, a separate percentage
  width-change graph with its actual allowance, and two missing-side lanes.
  Its paired deviation range uses 1.35 × tolerance instead of 3 × tolerance.
  Other search modes keep their previous plot range.
- The right-hand SVG adds a width graph, actual/reference width tooltips and
  explicit short-event explanations. `rowWidthReject` / JSON `width_reject` marks
  entire width-change runs reaching the existing length threshold. Orange means
  width exceeded its allowance for a shorter run; red means enough length, or a
  geometric tolerance violation. The source paths, mask PNG and plots agree.
  This is derived display metadata: rejection formulas and measured paths are unchanged.
- Each seam result includes `used_params`. The UI reports the exact settings of
  the displayed inspection, and shows a warning when the working draft differs.
  Moving a slider does not silently recompute an old image or graph. Reinspection
  updates the settings snapshot and removes the warning.

All detector settings, references, learned data and geometry are preserved. In
particular, no old 3.8/5.4 or 8/24 values are automatically restored while the owner
is tuning. The original signal-quality/calibration limitations remain open.
